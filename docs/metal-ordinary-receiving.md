# Ordinary receiving for mixed XYZ/group-B refinement

Updated 25 November 2026. A01 mechanical integration; A01 science remains partial
and A02 quantitation is gated. This is a prospective implementation contract,
not a claim of ordinary numbered-round qualification.

## What is qualified

The explicit scope, passive native observer, source-bound writer and literal
compositor preserve independently selected XYZ atoms and ordered disjoint B
groups while protecting Q/f′/f″ and nonselected B/XYZ. Existing evidence includes
one observed native cycle, exact selection compiler checks and zero-cycle source/
installed composition. Each receipt retains its own code pins; do not relabel old
cycles as qualification of later code. See the [handoff](metal-development-handoff.md#a01-parameter-scope-2026-11-25).

The compositor consumes exact policy bytes and expected SHA-256, `ParameterScope`
and its PDB source bytes. Its schema-1 `source-literal-parameter-composition-v1`
receipt pins source policy/model/scope/result and retained non-owned literals.
It removes all existing definitions for exactly eight strategy/XYZ/B/protection
fields before inserting replacements. It preserves scientific scalar literals,
including fixed f′, instead of whole-object PHIL float formatting. No operational
paths or execution/admission authority are introduced by this receipt.

## New source-to-target handoff qualification

The passive `refinement_diffraction_observation` helper now reuses existing metal
signatures/audits. Its schema-1 `exact-merged-hl-observation-v1` reference pins
independently admitted merged observations, boolean Free-R and HL captures, plus
original data/phase-file hashes. It reads no files and supplies no ancestry.
The old common amplitude-scaling allowance is explicitly disallowed for this
scope. Native arrays must be aligned, positive, crystal-consistent and bound to
the actual MLHL target manager. Parameter strategy stays independently protected.

25 source and 25 installed native cases pass. One 7.90-second dry handoff retains
1,151 observations, 59 Free assignments and 1,151 HL coefficients at three complete
model/target observations alongside the unchanged parameter observer. Zero cycles,
zero optimizer evaluations, both links and all protected Hg values retained. This
closes source-capture comparison through the private receiving control; **step 2's
ordinary ancestry/admission and steps 3–5's integration remain open**. Do not rerun
the qualified dry control merely because this prospective checklist remains open.

## Ordered integration steps

1. **Admit a legitimate prepared parent.** Reuse Cedar's `PreparedBackbone`,
   phosphate request, declared-site and numbered-round owners. Retain ordered
   inherited dictionary/restraint inputs, chemistry/terminal decisions, registered
   crystal-image bonds, source REVIEW status and run-context/checksum references.
   A private successful control is not permission to invent parent ancestry.
2. **Bind diffraction and phase sources independently.** Declare original
   anomalous amplitudes/sigmas, original Free-R column/test value and original HL
   quartet. Require indexed coverage, crystal agreement and explicit Bijvoet
   averaging for merged MLHL geometry. SAflags cannot substitute for Free-R.
   Retain exact amplitude/sigma/flag/HL values and actual target use. The current
   dry receipt covers these checks privately; ordinary admission is still open.
3. **Compose one policy under a new version.** Use the existing phase/fixed-
   scattering writer plus the maintained literal compositor. Preserve frozen
   V11/V12 code and every earlier payload digest; introduce a distinct runtime
   policy only when its dependencies and controls are complete. No new executor.
   Fixed anomalous-data refinement and merged MLHL geometry are different
   contracts. Do not weaken one to make the other pass.
4. **Observe throughout the existing owner.** Bind exact initial atoms and
   scattering; check model and diffraction state at initialization/stage/output,
   actual XYZ minimizer flags/parameters and group-B membership/shifts. Preserve
   phase/Free-R/target and registered-link checks. Final state alone cannot prove
   intervening protection. Restore callbacks on failure and success.
5. **Close output and process evidence.** Reuse existing native runtime output
   synchronization and outer process-stopping owner. Match full-precision native
   state before a separate format-aware serialized-model comparison. Never apply
   full-precision guards to rounded PDBs. Retain explicit failure/timeout outputs;
   no checkpoint selection on an incomplete receipt.
6. **Only then connect the scientific endpoint.** Independently qualify geometry,
   maps and fit. Estimate metal B from accepted refined base-only/donor environments
   (not starting model, sugar or backbone), then freeze XYZ/B/Q per f″ trial with
   fixed f′. Preserve ambiguity and human selection. No B=25 default or endpoint
   acceptance follows from this integration.

## Storage and compatibility

Keep one protected policy/scope/source bundle per important geometry parent.
Cheap f″ siblings retain input variables, source links, compact stats and bounded
maps until selection. No cleanup in this contract authorizes deleting immutable
runs or evidence. Paths must use declared anchors plus checksums. Existing
checkpoints and historical runtime bytes remain readable; there is no migration.
Generated crystallographic files and machine-local evidence remain outside Git.
